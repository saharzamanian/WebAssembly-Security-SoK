# The Fast and the Vulnerable: A Systematization of WebAssembly Security

This repository accompanies the paper **“The Fast and the Vulnerable: A Systematization of WebAssembly Security”** by **Sahar Zamanian, Sara Ramezanian, and Maria Kihl**.

Sahar Zamanian and Maria Kihl are affiliated with **Lund University**, and Sara Ramezanian is affiliated with **Karlstad University**.

## About the Paper

The paper presents a **Systematization of Knowledge (SoK)** of WebAssembly (Wasm) security research based on **135 peer-reviewed studies published since 2017**.

The surveyed literature is systematically analyzed and classified across several dimensions, including:

* Vulnerable WebAssembly components
* Attack and exploitation techniques
* Adversarial models
* Application domains and use cases
* Detection and mitigation techniques
* Security frameworks and tools

The study also examines relationships between these dimensions to provide a broader view of the WebAssembly security landscape.

In addition, the paper identifies several open challenges and research directions, including:

* Memory safety
* Cross-language security analysis
* Multi-tenant isolation
* Malware detection
* Evaluation datasets and benchmarks
* Security implications of emerging WebAssembly features

## Repository Contents

This repository provides the research artifacts used in our Systematization of Knowledge:

* **`DataExtractionWASM.csv`** — The data extraction dataset containing information collected from the 135 scientific studies included in the review.
* **PDF file** — The document used as part of the Systematization of Knowledge study.

## Dataset

The dataset contains the information extracted from the selected WebAssembly security studies and was used to categorize and analyze the existing body of research.

The extracted data covers key aspects of WebAssembly security research, including:

* Application domains and use cases
* Vulnerable components
* Attack and exploitation techniques
* Adversarial models
* Detection approaches
* Mitigation techniques
* Security frameworks and tools

The dataset also enables cross-analysis of relationships between:

* Vulnerabilities and attack techniques
* Attacks and WebAssembly components
* Vulnerabilities and application domains
* Defensive techniques and attack classes
* Existing research areas and identified research gaps

These data support the analyses, classifications, and conclusions presented in the paper and may also be useful for researchers interested in further studying the WebAssembly security ecosystem.
