# The Fast and the Vulnerable: A Systematization of WebAssembly Security

This repository contains the content related to the paper **“The Fast and the Vulnerable: A Systematization of WebAssembly Security”** by Sahar Zamanian, Sara Ramezanian, and Maria Kihl.
Sahar Zamanian and Maria Kihl are affiliated with **Lund University**, and Sara Ramezanian is affiliated with **Karlstad University**.

## About the Paper

The paper presents a Systematization of Knowledge (SoK) on WebAssembly (Wasm) security. We reviewed **135 peer-reviewed studies published since 2017** and categorized the existing research based on different aspects of Wasm security, including vulnerable components, attacks and exploitations, adversarial models, application domains, and detection and mitigation techniques.

Based on this analysis, we also discuss open research challenges in areas such as memory safety, cross-language analysis, multi-tenant isolation, malware detection, evaluation datasets, and emerging Wasm features.

## Repository Contents

This repository provides the research artifacts used in our Systematization of Knowledge:

* **`DataExtractionWASM.csv`** — The data extraction dataset containing information collected from the 135 scientific studies included in the review.
* **PDF file** — The document used as part of the Systematization of Knowledge study.

## Dataset

The dataset contains the information extracted from the 135 studies included in the SoK. This data was used for the classifications and analyses presented in the paper. 

The extracted information covers topics such as:
* Application domains and use cases of WebAssembly
* Vulnerable Wasm components
* Attacks and exploitation techniques
* Adversarial models
* Detection and mitigation techniques
* Research Gaps
* Security frameworks and tools

We also used the dataset to study relationships between these categories, for example, between vulnerabilities, attacks, Wasm components, application domains, and defensive techniques.
