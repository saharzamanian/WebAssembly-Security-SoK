# WebAssembly-Security-Vulnerabilities-SoK
This repository contains the data extraction dataset (`DataExtractionWASM.csv`) and the PDF file used in our Systematization of Knowledge (SoK) on WebAssembly (Wasm) security. The data are extracted from 135 peer-reviewed studies published since 2017 and support the systematic analysis presented in the paper.

The extracted data covers key dimensions of Wasm security research, including application domains and use cases, vulnerable components, attack and exploitation techniques, adversarial models, detection and mitigation approaches, and security frameworks and tools. The dataset also supports the cross-analysis of relationships between vulnerabilities, attacks, Wasm components, application domains, and defensive techniques, as well as the identification of research gaps and future directions.
